# Deckforge

An AI presentation builder in the spirit of Gamma. Describe what you want to present; Deckforge
plans an outline you can edit, then writes a themed deck card by card. Edit any card, regenerate it
with instructions, reorder, switch themes in one click, present full-screen, share a link or download a PDF.

## Features (first version)

- **Prompt → outline → deck.** The outline step lets the user fix the structure before anything is written.
- **Cards appear one by one.** Each card is generated by its own request (3 at a time), so the deck fills in progressively and one failure doesn't sink the deck. Reloading the editor resumes unfinished cards.
- **7 card layouts:** title, section, bullets, columns, big numbers, quote, timeline. The AI picks the layout per card.
- **Editing:** edit form per card, regenerate with optional instructions ("shorter", "make it a timeline"), add, delete, reorder.
- **6 themes:** Minimal, Midnight, Ocean, Sunset, Forest, Paper.
- **Present mode:** full screen, arrow keys / click / Esc.
- **Share and PDF:** a view-only link (`/d/<id>`), with "Download PDF" printing one 16:9 card per page.

## How it works

| Piece | Where |
| --- | --- |
| Pages | `src/app/page.tsx` (create), `src/app/d/[id]/edit` (editor), `src/app/d/[id]` (shared view) |
| API | `src/app/api/outline`, `src/app/api/decks/...` |
| AI | `src/lib/ai.ts`: structured outputs (Zod schemas in `src/lib/cards.ts`) via the Anthropic SDK |
| Data | Prisma + SQLite (`prisma/schema.prisma`): `Deck` and `Card` |
| Look | `src/components/CardView.tsx` + themes in `src/app/globals.css` |

**AI details.** Default model `claude-opus-5-5` (override with `DECK_MODEL`). Outlines run at low effort,
cards at medium. The writing instructions and the deck's context are a cached prompt prefix shared by all
cards of a deck, which keeps per-deck cost down. If the model declines a request, the API's server-side
fallback retries it on a fallback model.

**No accounts yet.** Creating a deck returns a secret edit token that the creating browser keeps in
localStorage; the server stores only its hash. Anyone with the link can view; only that browser can edit.

**Abuse limits.** Per-IP hourly limits (30 outlines, 10 decks, 200 card generations), in memory.

## Run it

Requires Node 20.9+ and an [Anthropic API key](https://console.anthropic.com).

```bash
npm install
cp .env.example .env        # then put your ANTHROPIC_API_KEY in .env
npx prisma migrate dev      # creates the local SQLite database
npm run dev                 # http://localhost:3000
```

Checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Next steps toward a product

1. **Accounts** (e.g. Auth.js or Clerk) so decks are saved per user and editable from any device.
2. **Billing** with Stripe or Lemon Squeezy: free tier with credits, paid plans for more decks, no watermark, custom branding.
3. **Images:** stock photos (Unsplash/Pexels API) or an image-generation API per card.
4. **Postgres** (Neon/Supabase free tier) and hosting on Vercel; move rate limits to Redis/Upstash.
5. **PPTX export** and custom brand themes (logo, colors, fonts).
6. **Import:** turn a pasted document, PDF or URL into a deck.
